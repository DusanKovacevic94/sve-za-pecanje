# Moderation

Daily admin checklist:

1. Review pending listings.
2. Reject prohibited, misleading, duplicate, offensive, or suspicious listings.
3. Resolve open reports.
4. Suspend abusive users.
5. Feature selected listings manually.
6. Check message/report volumes for spam patterns.

Reject reasons should be clear and actionable:

- Nedostaju informacije
- Neodgovarajuća kategorija
- Zabranjen predmet
- Sumnja na prevaru
- Dupliran oglas
- Neprimeren sadržaj
- Ostalo

Every admin action is persisted to `audit_logs`.
